# GlassAlarm Updates

Encrypted differential software updates for GlassAlarm. Import your private update key and canonical base IPA in Settings → About once. Only changes are downloaded; the app authenticates, decrypts and reconstructs a complete IPA locally for SideStore installation.

This repository distributes update artifacts only. Keys, Apple signing credentials, model weights and source code are not hosted here. No installation or relaunch automation is implied. Third-party notices remain inside the reconstructed app.
