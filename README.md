# GlassAlarm Updates

Encrypted differential software updates for GlassAlarm. Install the configured full version once. Settings → About displays the latest release before you choose to update. Only changes are downloaded; the app authenticates, decrypts and reconstructs a complete IPA locally for SideStore installation.

This repository distributes update artifacts only. Keys, Apple signing credentials, model weights and source code are not hosted here. No installation or relaunch automation is implied. Third-party notices remain inside the reconstructed app.
